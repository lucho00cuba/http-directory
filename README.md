Practical guides to every HTTP status code.

Live site: [http-directory.justme.ovh](https://http-directory.justme.ovh/)

Inspired by [HTTP Guides](https://httpguides.com/) by [@jmstfv](https://github.com/jmstfv).

## Commands

```bash
pnpm install   # install deps
pnpm dev       # localhost:4321
pnpm build     # output → ./dist
pnpm preview   # preview production build
```

## URLs

Each status has two paths that render the same page:

- Short: `/status/100`
- Canonical: `/status/100-continue`
