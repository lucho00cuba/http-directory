The <abbr title="Hypertext Transfer Protocol">HTTP</abbr> 200 status code means a request was successful.

The server's response will depend on the HTTP method used:

<ul class="spec-list">
<li><code>GET</code> — The resource itself is returned (for example, a web page or a <abbr title="JavaScript Object Notation">JSON</abbr> response from an <abbr title="Application Programming Interface">API</abbr>)</li>
<li><code>HEAD</code> — Similar to GET, but it doesn't contain the resource itself, only HTTP headers</li>
<li><code>POST</code> — The result of a request (POST method is used to create/alter the resource)</li>
</ul>

`200 OK` is the most commonly used status code.
